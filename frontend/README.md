# Frontend Module — Mohsinon

Modern Web Application built with:
- Angular 18+ (Standalone Components, Signals)
- Custom SCSS Design System with HSL tokens
- TypeScript & Modern RxJS
- WCAG 2.1 AA Accessibility Standards

## Structure
```text
frontend/src/app/
├── core/                        # Singleton services, interceptors, auth guards
├── shared/                      # Reusable components, directives, pipes
├── layouts/                     # Page layouts (Main, Auth)
└── features/                    # Feature modules (Auth, Mosques, Donations, Initiatives, Skills, Profile)
```
